## Project Description

This project is a simple pizza order form made with HTML, CSS, and JavaScript. The user can enter their name, choose pizza options, pick toppings, and add special instructions. When the form is submitted, the page checks the inputs and creates a pizza object using a JavaScript class.

## Features

- Student name and ID shown on the page with JavaScript.
- Pizza order form with size, crust, sauce, cheese, toppings, and instructions.
- Basic validation before submitting.
- Pizza class with a method that returns the pizza summary.
- Order summary shown on the page after validation passes.

## Files

- `index.html` - Main page with the form.
- `styles.css` - Page styling.
- `app.js` - Form validation and Pizza class.

## How to Run

1. Open the project folder in VS Code.
2. Open `index.html` with Live Server.
3. Fill out the form and click Order.
